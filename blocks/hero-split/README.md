# hero-split

Custom **hero** block. Purpose: Top-of-page banner with the page title on a solid panel beside a photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: image; row 2: H1 heading (optional paragraphs). Cell order is not significant: the first picture becomes the media column, everything else the text panel.

## Supported variations

No variations.
