# tabs-findings

Custom **tabs** block. Purpose: Topic tabs where each panel shows key findings beside an image, with a collapsible list of related reports and links.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: [tab label | panel content]. Panel content in order: H2 (e.g. 'Key findings'); H3 headline; summary paragraph; CTA link; image; H3 collapsible title (e.g. 'Reporting and analysis'); then one or more H4 group headings, each followed by a list or paragraphs of links. The collapsible starts at the last H2/H3 before the first H4; picture-only paragraphs before it form the right-hand image column.
